문제

꽃길 정보는 예쁘지만, 방문 판단은 여전히 어렵습니다.

계절 꽃 명소는 상태가 빠르게 바뀝니다. 방문자는 블로그, 지도 리뷰, SNS 게시물을 따로 확인해야 하고, 오늘 가도 괜찮은지 판단하기 어렵습니다.

꽃길은 코스 큐레이션, 계절 필터, 저장한 장소, 접근성 메모, 짧은 현장 제보를 모바일 경험 안에 모아 실제 방문 결정을 쉽게 만듭니다.

✿

계절별 탐색

지금 계절에 보기 좋은 꽃과 코스를 우선 보여주고, 방문 타이밍을 좁혀줍니다.

⌁

산책 코스

✓

현재 파일럿

작게 검증하고, 지역별로 확장합니다.

기술 계획

작고 안정적인 파일럿 인프라부터 시작합니다.

현재 꽃길 백엔드는 Go 기반 API 서비스와 Supabase/PostGIS 데이터 레이어를 사용합니다. AWS 크레딧은 비공개 테스트에서 안정적인 프로덕션 파일럿으로 옮기는 데 활용할 계획입니다.

API 호스팅

코스, 커뮤니티 업데이트, 사용자 기능을 위한 Go API를 저비용 구조로 운영합니다.

코스 데이터 전달

사용자가 늘어나도 지도·코스 관련 정적 데이터를 안정적으로 제공합니다.

관측성

파일럿 기간 동안 로그, 오류, 지연 시간, 서비스 상태를 확인합니다.

AI 보조 기능

현장 제보 분류, 개화 상태 요약, 코스 추천을 사람 검수와 비용 통제 하에 확장합니다.
